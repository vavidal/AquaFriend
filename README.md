Sobre AquaFriend – Vistas 360° Acuario Puyehue

AquaFriend es una plataforma web educativa e interactiva desarrollada para el Acuario de Puyehue y su Granja Educativa.
El sistema permite recorrer virtualmente distintas zonas mediante vistas 360°, ofreciendo una experiencia inmersiva y accesible desde cualquier dispositivo.
Su propósito es acercar la educación ambiental a estudiantes, familias y público general, eliminando barreras geográficas, físicas y económicas mediante tecnología web moderna.

Las zonas disponibles incluyen:

Granja Educativa

Coto de pesca

Miradores

Áreas interiores del acuario

Sectores informativos y educativos

Requisitos

Para ejecutar correctamente el software y el panel administracion, se requieren los siguientes componentes:

Requisitos mínimos

Node.js 18+

Angular 17+

MySQL 8.x como gestor de base de datos

API backend desarrollada en Node.js + Express

Git instalado para control de versiones

También te recomendamos tener:

Extensiones del navegador para desarrolladores, como Angular DevTools.

XAMPP /PHPadmin para administrar la base de datos durante el desarrollo.

GitHub Desktop para mantener el repositorio sincronizado.
